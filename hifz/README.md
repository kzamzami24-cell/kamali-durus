# خزانة المحفوظات

موقع لمتابعة حفظ المتون العلمية ومراجعتها. كل مشارك يدخل بحساب Google، فتُحفظ متونه وخططه وسجلّه في حسابه وحده.

- `index.html`: الموقع كاملًا (ملف واحد بلا مكتبات بناء).
- `firebase-config.js`: إعدادات Firebase (مشروع kamali-durus نفسه).
- `firestore.rules`: قواعد Firestore؛ أُضيفت مجموعة `hifz/{uid}` بجانب قاعدة مجالس الكملي.
- `nukhba/`, `jazari/`, `nazm/`, `qawaid/`: صفحات المتون.
- `audio/`: التلاوات الصوتية (من أرشيف الإنترنت).
