# مجالس الكملي

موقع يجمع قوائم تشغيل دروس الشيخ سعيد الكملي على يوتيوب (قناته الرسمية، والقناة الاحتياطية، وقوائم دروس من قنوات أخرى) في مكان واحد، بلا تكرار، مع متابعة التقدّم في كل درس وكل سلسلة.

## كيف يعمل

- `index.html` و`style.css` و`app.js`: الموقع نفسه، ملفات ثابتة بلا أي مكتبات.
- `catalog.json`: فهرس السلاسل والدروس الذي يقرؤه الموقع.
- `data/sources.json`: القنوات والقوائم المتابَعة، والقوائم المستبعدة، والأسماء المعدّلة.
- `data/raw.json`: آخر ما جُلب من يوتيوب.
- `scripts/fetch.py`: يجلب القوائم من يوتيوب. يكتشف أي قائمة جديدة في القناتين الرسميتين تلقائيًا.
- `scripts/build.py`: يوحّد المقاطع المكررة، ويدمج القوائم المتطابقة، ويضع كل درس في سلسلة واحدة، ويرتّب الدروس بأرقامها.
- `.github/workflows/update.yml`: يشغّل الجلب والبناء مرتين يوميًا ويحفظ الفهرس الجديد، فتظهر الدروس الجديدة في الموقع تلقائيًا.

## التقدّم

يُحفظ تقدّمك في متصفّحك (موضع التوقف في كل درس، وما أتممته). زر السهم أعلى الصفحة يصدّر ملف التقدّم ويستورده لنقله بين الأجهزة.

## مفتاح YouTube API (اختياري)

يعمل التحديث دون مفتاح عبر yt-dlp. لتحديث أدق وأثبت أضف مفتاح YouTube Data API v3 باسم `YT_API_KEY` في:
Settings ← Secrets and variables ← Actions ← New repository secret.

## إضافة قائمة أو استبعادها

عدّل `data/sources.json`: أضف معرّف القائمة إلى `extra_playlists`، أو إلى `exclude` لاستبعادها، ثم شغّل سير العمل يدويًا من تبويب Actions.
